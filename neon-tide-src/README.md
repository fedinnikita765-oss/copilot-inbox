# Neon Tide — исходники

Здесь лежит код игры по модулям. Готовый файл `../neon-tide.html` собирается из них командой `node build.js`.

## Сборка

```
npm install
npm run build
```

После сборки появятся два файла:

- `../neon-tide.html` — основной файл, three.js встроен, работает без интернета;
- `dist/neon-tide.cdn.html` — версия для публикации артефактом на claude.ai, three.js подгружается с jsDelivr.

## Проверка

Для тестов нужен Chromium для Playwright: `npx playwright install chromium`.

- `npm test` — открывает обе сборки, запускает игру и проверяет, что в консоли 0 ошибок.
- `npm run test:logic` — проходит весь сценарий: пешком и в машине, дрифт, перекраска, погоня, арест, все миссии, курьер, взрыв, респаун.

В тестах используется `window.__neon` — отладочный доступ к состоянию игры и функция `step(n, dt)`, которая прокручивает логику без отрисовки.

## Устройство кода

Файлы из `src/js` склеиваются в одну функцию по порядку имён.

| Файл | Что внутри |
| - | - |
| `01_core.js` | Рендерер, качество графики, процедурные текстуры, небо, океан, свечения, частицы, смена дня и ночи |
| `02_city.js` | Планировка города, здания с шейдером фасадов, дороги, фонари, пальмы, пирс, маяк, сетка коллизий, мини-карта |
| `03_entities.js` | Машины: модели, аркадная физика, столкновения, повреждения |
| `03b_humans.js` | Люди: скиннинговые модели (18 костей) и процедурная анимация |
| `04_ai.js` | Трафик, пешеходы, полиция, уровень розыска |
| `05_game.js` | Игрок, камера, вождение, миссии, маркеры, подбираемые предметы |
| `06_audio.js` | Синтезированный звук и радио |
| `07_hud.js` | Интерфейс, мини-карта, сенсорное и клавиатурное управление |
| `08_main.js` | Загрузка, меню, пауза, главный цикл |

`src/head.html` содержит стили, `src/body.html` — разметку интерфейса.
